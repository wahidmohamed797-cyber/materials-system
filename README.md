# رَوّاد - إدارة مخازن الخامات

واجهة عربية لإدارة مخازن الخامات والفوارغ، حركات المخزون، والأرصدة والتقارير باستخدام Supabase.

## التشغيل

افتح `index.html` في المتصفح. يتصل التطبيق بمشروع Supabase المحدد في `supabase-config.js`.

لتجهيز قاعدة بيانات جديدة، شغّل محتوى `supabase.sql` من SQL Editor في مشروع Supabase، ثم أنشئ حساب المالك من التطبيق. المفتاح الموجود في `supabase-config.js` هو publishable key مخصص للاستخدام في الواجهة؛ لا تضع مفتاح `service_role` في ملفات المتصفح أو GitHub.

# رَوّاد - إدارة مخازن الخامات

واجهة عربية لإدارة مخازن الخامات والفوارغ، حركات المخزون، والأرصدة والتقارير باستخدام Supabase.

## التشغيل

افتح `index.html` في المتصفح. يتصل التطبيق بمشروع Supabase المحدد في `supabase-config.js`.

لتجهيز قاعدة البيانات أو بعد أي تحديث على الملف، شغّل محتوى `supabase.sql` كاملًا من SQL Editor في مشروع Supabase، ثم أنشئ حسابًا من التطبيق. كل حساب له بياناته المعزولة. الأرصدة تُحسب داخل Postgres ولا يعتمد النظام على تحميل كل الحركات إلى المتصفح.

المفتاح الموجود في `supabase-config.js` هو publishable key مخصص للاستخدام في الواجهة؛ لا تضع مفتاح `service_role` في ملفات المتصفح أو GitHub.
